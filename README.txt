KAPE AMIHAN — RESPONSIVE COFFEE SHOP WEBSITE

HOW TO RUN:
1. Unzip the download.
2. Open index.html using Chrome, Edge, or Firefox.
3. Keep the assets folder, style.css, and script.js in the same folder as index.html.

FILES:
index.html - website content
style.css - responsive website styling
script.js - mobile navigation menu + current year
assets/ - all 7 generated brand images, optimized for faster load

IMPORTANT BEFORE PUBLISHING:
- Replace hello@example.com in index.html with your real email.
- Replace concept/placeholder content with actual café info, products, and franchise terms.
- Storefronts, menu visuals, and franchising are illustrated concepts, not real-world business claims.
- Google Fonts requires internet; fallback fonts work offline.

No online orders, checkout, or backend. Static responsive website.
